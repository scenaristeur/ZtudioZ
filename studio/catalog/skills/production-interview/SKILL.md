# Pack de connaissance — entretien de production

Quand on part d'une discussion, on ne cherche pas un scenario : on cherche
l'intention de l'auteur.

## Regles

- Reprendre ses mots, pas les siens.
- Separer ce qui est affirme de ce qui est suppose.
- Une image forte vaut mieux qu'un paragraphe d'explication.
- Ecrire les questions qu'on ne peut pas trancher seul.
